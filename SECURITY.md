# Security Policy

## Supported Versions

Este projeto é um site estático desenvolvido com HTML, CSS e JavaScript.

| Version | Supported          |
| ------- | ------------------ |
| 1.x.x   | :white_check_mark: |
| < 1.0   | :x:                |

## Reporting a Vulnerability

Se você encontrar algum problema de segurança no projeto, por favor, abra uma **Issue** neste repositório descrevendo o problema.

Inclua, se possível:

* Uma descrição do problema
* Como reproduzir o problema
* Qual arquivo ou página é afetado
* Qualquer informação adicional que possa ajudar na investigação

Problemas de segurança serão analisados e, quando necessário, corrigidos em uma atualização do projeto.

Obrigado por ajudar a manter o projeto seguro! 🛡️
