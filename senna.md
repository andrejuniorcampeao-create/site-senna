# 🏎️ Ayrton Senna da Silva 🇧🇷

Um site criado para apresentar a história, carreira e legado de **Ayrton Senna da Silva**, um dos maiores pilotos brasileiros da Fórmula 1.

## 📖 Sobre o projeto

O site contém informações sobre Senna, sua carreira na Fórmula 1, seus títulos, curiosidades e um documentário incorporado.

## 📂 Arquivos

* `index.html` → página principal
* `senna2.html` → página sobre Ayrton Senna
* `css.css` → estilo da página principal
* `ss.css` → estilo da página `senna2.html`
* `javascript.js` → funcionalidades em JavaScript

## 🎬 Conteúdo

O site também possui um vídeo incorporado do YouTube sobre Ayrton Senna.

## 🏁 Tecnologias

* HTML
* CSS
* JavaScript
